# 生理ノート

2人分の生理周期を記録して、次回の目安が分かるWebアプリです。

## できること
- 2人分のプロフィールを切り替えて、それぞれの周期を記録
- 平均周期・平均期間から、次回の開始目安と「生理前の時期」を自動計算
- カレンダー表示（生理期間・次回の予測・生理前の時期・チェック済みの日が一目で分かる）
- その日の体調・痛み・気分を、質問に答える形式でかんたん入力（複数選択OK）
- 記録をファイルに書き出してパートナーとシェア（読み込み対応）
- サンプルデータでおためし可能

## 使い方
ブラウザで開くだけで使えます。データは開いた端末の中（localStorage）にだけ保存され、外部に送信されることはありません。

## 注意
次回の予測は記録の平均から計算した「目安」です。体調の変化などでずれることがあります。医療的な判断には使わないでください。

## 技術
- 単一HTMLファイル（HTML / CSS / JavaScript）
- データ保存：localStorage
